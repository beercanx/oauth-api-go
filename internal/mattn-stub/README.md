# Stub for github.com/mattn/go-sqlite3

This stub is used to replace [github.com/mattn/go-sqlite3](https://pkg.go.dev/github.com/mattn/go-sqlite3) 
with [github.com/ncruces/go-sqlite](https://pkg.go.dev/github.com/ncruces/go-sqlite3) 
because [github.com/golang-migrate/migrate/v4](https://pkg.go.dev/github.com/golang-migrate/migrate/v4) forces `mattn` on us.
